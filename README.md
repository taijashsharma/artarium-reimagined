#  Artarium Reimagined - Luxury Interior & Decor Portal

Artarium Reimagined is a high-end digital showroom designed for premium interior decor and home styling. The platform showcases a curated collection of luxury furniture, artisanal sculptures (Murti), and modern interior elements with a focus on minimalist aesthetics and high performance.

##  Product Categories
*   **Signature Furniture:** Designer sofa sets, ergonomic chairs, and statement tables.
*   **Artisanal Sculptures:** Handcrafted Murtis and contemporary art pieces for home sanctuaries.
*   **Interior Accents:** Premium lighting, rugs, and decorative wall art.
*   **Consultation Hub:** Interface for clients to connect with professional interior designers.

##  Key Features
*   **Premium Visual Gallery:** High-definition rendering of decor items using optimized image processing.
*   **Modern UI/UX:** Built with **Shadcn UI** and **Tailwind CSS** for a "Luxury Brand" feel.
*   **Responsive Showcase:** Fully optimized for mobile, tablet, and desktop viewing.
*   **Fast Navigation:** Powered by **Vite** for a seamless, lag-free browsing experience.

##  Technical Stack
- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS
- **Components:** Shadcn UI / Radix UI
- **Icons:** Lucide React (for a clean, minimal look)
- **State Management:** React Hooks

##  Vision
To bridge the gap between traditional interior craftsmanship and modern digital accessibility, providing clients with an immersive way to visualize their dream homes.
